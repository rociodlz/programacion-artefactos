Laboratorio 5 - ESP32 y conexión a Internet en Adafruit

Introducción a Adafruit

Adafruit es una empresa y un ecosistema dedicado al desarrollo de hardware, software y herramientas para electrónica, programación e Internet (IoT).

Fue fundada por Limor Fried y ofrece componentes electrónicos, placas de desarrollo, sensores, pantallas, librerías y plataformas para facilitar la creación de proyectos.

¿Qué es Adafruit IO?

Adafruit IO es una plataforma en la nube orientada a proyectos de IoT.

Permite que un dispositivo conectado a Internet pueda enviar datos a la nube y recibir instrucciones desde ella.

Por ejemplo: Desde la placa ESP32 y un sensor de temperatura, haciendo uso de Adafruit IO, se puede mostrar el valor obtenido mediante una gráfica y que el dato se esté actualizando constantemente.

¿Qué es un Feed?

Un Feed es un espacio dentro de Adafruit IO utilizado para manejar los datos de una determinada variable.

Por ejemplo: Todas las variables que queramos utilizar como temperatura, humedad, luz, nivel de agua, estado de sensores, etc.

¿Qué es un Dashboard?

Un Dashboard permite presentar visualmente la información de un proyecto.

Debemos utilizar los que más se adecúen a nuestros sensores, pueden ser gráficas, valores numéricos, botones, controles, etc.

Ventajas

Entre las principales ventajas de utilizar el ecosistema Adafruit están:

  • Facilita el aprendizaje de electrónica.
  • Tiene una gran cantidad de librerías y documentación.
  • Permite trabajar con muchos sensores y dispositivos.
  • Facilita la creación de proyectos IoT.
  • Permite visualizar información mediante dashboards.
  • Permite realizar proyectos de monitoreo y automatización.
  • Se puede utilizar con plataformas como Arduino, ESP8266 y ESP32.

Mapa de pines de ESP32

Sensor ultrasónico HC-SR04

El HC-SR04 es un sensor de distancias por ultrasonidos capaz de detectar objetos y calcular la distancia a la que se encuentra en un rango de 2 a 450 cm. El sensor funciona por ultrasonidos y contiene toda la electrónica encargada de hacer la medición.

Pines de conexión

  • VCC
  • Trig (Disparo del ultrasonido)
  • Echo (Recepción del ultrasonido)
  • GND

Funcionamiento

El sensor ultrasónico funciona enviando un pulso de sonido (ultrasonido, fuera del rango audible) por el pin TRIG, y midiendo cuánto tiempo tarda ese sonido en rebotar contra un objeto y regresar, lo cual detecta en el pin ECHO. Cuanto más lejos esté el objeto, más tiempo tarda el sonido en ir y volver.

El cálculo se basa en la fórmula física de velocidad, distancia y tiempo:

v = d / t    →    d = v × t

El tiempo que mide el sensor (la duración en que el pin ECHO se mantiene en alto) corresponde al recorrido de ida y vuelta del sonido, no solo a la ida. Por eso, la distancia real hasta el objeto es la mitad de lo que el sonido recorrió en ese tiempo:

d(cm) = (0.0343 × t(µs)) / 2

Configuración de Adafruit

Paso 1:

En el Arduino IDE, ve al menú Sketch -> Include Library, selecciona Manage Libraries. Tambien puedes utilizar el icono de libro en la barra lateral izquierda.

Paso 2:

En el buscador del Library Manager escribe “Adafruit IO Arduino” y localiza la librería oficial publicada por Adafruit. Haz clic en Install, y acepta instalar todas las dependencias.

Paso 3:

Ahora verificamos que las librerías quedaron instaladas. Vuelve a abrir el Library Manager, escribe "Adafruit" en el buscador y cambia el filtro Type a Installed. Debe aparecer Adafruit IO Arduino junto con sus dependencias, todas marcadas como "installed".

Lo importante es confirmar que Adafruit IO Arduino aparezca instalada.

Paso 4:

Ahora debemos obtener el Usuario y la AIO Key de nuestra sesion de adafruit.com. En la esquina superior derecha, haz clic en el icono amarillo con forma de llave

Se abrirá una ventana con tu Username y Active Key (AIO Key). Estas dos credenciales son las que se usaran en el codigo para conectar el ESP32 a Adafruit IO.

Tu Active Key funciona como una contraseña: cualquiera que la tenga puede leer, modificar tus feeds, y controlar tus widgets.

Actividad práctica: Ultrasónico + LED RGB + Adafruit IO

En esta actividad se conecta el sensor ultrasónico HC-SR04 a Adafruit IO para publicar la distancia medida en tiempo real, visible en un dashboard mediante un widget y un LED RGB que su color cambia según la distancia del objeto; verde para objetos lejanos, amarillo para objetos medios y rojo para objetos cercanos.

Creación de Feeds y Widgets en el Dashboard

Paso 1:

Para crear un Feed debes ir a el menú superior de Adafruit IO, hacer clic en Feeds y luego en el botón New Feed.

Se abrirá un formulario donde debes escribir el nombre del feed (por ejemplo "distancia") y, opcionalmente, una descripción. Luego haz clic en Create.

El nuevo feed aparecerá listado bajo el grupo "Default", junto con su Feed Key (el nombre que se usará en el código para identificarlo).

Paso 2:

Para crear un nuevo Dahboard, haz clic en Dashboards y luego en New Dashboard.

Escribe un nombre para el dashboard (por ejemplo "Sensor Ultrasónico") y, opcionalmente, una descripción. Haz clic en Create.

El dashboard quedará creado y listado, listo para agregarle widgets.

Paso 3:

Dentro del dashboard, haz clic en el botón New Block, ubicado en la esquina superior derecha.

Se abrirá una ventana con todos los tipos de bloques disponibles. Para mostrar la distancia del sensor ultrasónico, elige el bloque Gauge (medidor circular).

En la siguiente pantalla, te pedirá elegir a qué feed se conectará el bloque.

Marca el checkbox del feed correspondiente (por ejemplo "distancia" para el Gauge) y haz clic en Next step.

Configura los datos del bloque, como título, rango, etiqueta de unidades, luego haz clic en Create Block.

Puedes reordenar los widgets arrastrándolos dentro del dashboard, y editarlos en cualquier momento haciendo clic sobre cada bloque.

  }

// Promedia varias lecturas para reducir el ruido
float distanciaPromedio(int muestras) {
  float suma = 0;
  int validas = 0;
  for (int i = 0; i < muestras; i++) {
    float d = leerDistanciaCm();
    if (d > 0) { suma += d; validas++; }
    delay(40);   // espera entre mediciones para que no se mezclen los ecos
  }
  return (validas > 0) ? suma / validas : -1;
}

void conectarWiFi() {
  Serial.print("Conectando a "); Serial.println(WLAN_SSID);
  WiFi.begin(WLAN_SSID, WLAN_PASS);
  while (WiFi.status() != WL_CONNECTED) {

void conectarMQTT() {
  if (mqtt.connected()) return;

  Serial.print("Conectando a Adafruit IO... ");
  int8_t ret;
  uint8_t intentos = 3;
  while ((ret = mqtt.connect()) != 0) {         
    Serial.println(mqtt.connectErrorString(ret));
    Serial.println("Reintentando en 5 segundos...");
    mqtt.disconnect();
    delay(5000);
    if (--intentos == 0) {
      Serial.println("No se pudo conectar. Reiniciando la ESP32...");
      ESP.restart();
    }
  }
  Serial.println("¡Conectado a Adafruit IO!");
}

Desafío: apagar el LED desde Adafruit con un Toggle

Se debera agregar un botón tipo Toggle en el dashboard que permita encender o apagar el LED RGB desde Adafruit IO.

Para esto es necesario crear un nuevo feed. A diferencia del feed distancia, este feed no lo publica el ESP32, sino que el ESP32 se suscribe a él para recibir los cambios que la persona haga desde el dashboard.

  • Declarar una nueva suscripción con Adafruit_MQTT_Subscribe apuntando al nuevo feed.
  • Suscribirse a ese feed dentro de setup() con mqtt.subscribe(...).
  • Dentro de loop(), revisar con mqtt.readSubscription() si llegó un mensaje nuevo de ese feed.
Ambos feeds son independientes: uno se usa para publicar y el otro para recibir. No deben compartir el mismo nombre.
